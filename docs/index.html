01 / EDIT

Visual scene editor

Manage GameObjects, edit properties in the inspector and organize your scene with Dear ImGui panels.

↗
02 / SAVE

Scene serialization

Persist objects and global asset libraries so the same scene can be restored in a game build.

↗
03 / ANIMATE

Sprite-sheet animation

Create ID-based animation clips from a shared sprite sheet and trigger them directly from scripts.

↗
04 / LISTEN

Audio management

Load sound effects and music once, then reference and play them using stable numeric IDs.

↗
05 / SCRIPT

ScriptContext access

Write C++ behaviors with access to animation, audio and other engine services through ScriptContext.

↗
06 / SHIP

Editor → game build

Keep editor tools in Debug builds and produce an independent Release runtime using integrated build controls.

04 / GET STARTED

Clone. Build.
Create.

Everything starts with the source. Clone the repository, open the Visual Studio solution and build the editor.

PLATFORMWindows / Visual Studio + C++ toolchain

Build scripts currently target Visual Studio 2026 Community. If your installation differs, adjust the toolchain path in the scripts.
